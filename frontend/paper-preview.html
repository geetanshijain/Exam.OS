Section A — Short Answers (Compulsory)

20 Marks

1. Define the term 'system call' and differentiate between user mode and kernel mode privilege rings with hardware trap handling.

[4M]

2. Differentiate between preemptive and non-preemptive process scheduling with two concrete kernel examples.

[4M]

3. Explain the role of the Translation Lookaside Buffer (TLB) in speeding up virtual address translation.

[4M]

4. Describe the four Coffman conditions necessary for a resource deadlock to occur.

[4M]

5. Compare hard links and symbolic links in Linux ext4 filesystem in terms of inode pointers and reference counts.

[4M]

Section B — Analytical & Algorithmic Evaluation

40 Marks

6. Given the page reference string [7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2, 1, 2, 0, 1, 7, 0, 1] and 3 physical frames, calculate page faults under FIFO and LRU algorithms. Demonstrate why Belady's Anomaly cannot occur in LRU.

[10M]

7. Explain the classic Producer-Consumer synchronization problem using POSIX semaphores. Provide C code demonstrating proper mutex locking and buffer boundary checks to prevent deadlock.

[10M]

8. Consider a system with 5 processes (P0-P4) and 3 resource types (A, B, C). Execute Banker's Algorithm to determine if the current allocation state is safe. If a request from P1 arrives for (1, 0, 2), can it be granted immediately?

[10M]

9. Suppose a disk drive has 5000 cylinders (0 to 4999). The head is currently at cylinder 2150. Given the request queue [2069, 1212, 2296, 2800, 544, 1618, 356, 1523], calculate total head movement using C-SCAN in the upward direction.

[10M]

Section C — Comprehensive System Architecture

40 Marks

10. Architect a fault-tolerant, log-structured file system (LFS) with segment cleaning and checkpoint indexing. Contrast its crash recovery latency with traditional journaling filesystems under high-throughput write workloads.

[20M]

11. Design a multi-level virtual memory manager supporting inverted page tables, copy-on-write (COW) fork semantics, and demand paging. Provide mathematical derivations for effective access latency under 95% TLB hit ratio.

[20M]
